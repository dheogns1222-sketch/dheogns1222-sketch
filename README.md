# 오대훈

**QA 엔지니어**

QA 2년차고 그 전엔 서비스업에서 7년을 보냈다. 학벌이나 스펙보다는 필요한 걸 직접 만들어 쓰는 쪽이 익숙하다. 파견 QA로 6개 플랫폼, 9개 프로젝트를 거치면서 반복되는 보고 작업이 아까워서 자동화 도구를 만들었고, 지금 이 계정의 저장소 4개도 그 연장선이다.

---

## About

- 2023.10~2025.10 2년간 게임·소프트웨어 QA 파견으로 9개 프로젝트(8개 고객사)에 투입됐다. VR/MR, 모바일, PC, OTT, Web3, Telegram 6개 플랫폼을 검증했다.
- Meta Quest 타이틀의 VRC(Virtual Reality Check) 검수 대응, Web3 거래소의 KYC·2FA·오더북 QA, 대형 게임사 신규 프로젝트 파일럿 테스트 참여 같은 도메인 경험을 쌓았다.
- 수기로 반복되던 일일 테스트 보고를 Google Sheets와 Apps Script로 직접 설계해 4개 프로젝트에 배포했다.
- 지금은 ISTQB CTFL을 준비하면서 Playwright 기반 E2E 자동화를 익히고 있다.
